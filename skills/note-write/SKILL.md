# note-write — note本文を書く

承認された構成（note-outline）を、**あなたらしい本文**に仕上げる工程。文体ルールを最優先で守り、**AI感を消す**。

## 参照

- あなたの設定：`~/note-kit/profile.md`（**書き始める前に必ず読む**）

## 前提

- 構成が承認済みであること。まだなら **note-outline** を先に案内して止まる。

## 文体ルール（最優先）

設定ファイルの「文章のトーン」と「サンプル文」に従う。設定が空欄のときだけ、下を初期値として使う。

- 一人称・語尾は設定ファイルのとおりに。**ただし同じ語尾を連打しない**（文末を不揃いにする）
- 一文は短め（1〜2行）、1段落は2〜3文
- **太字**でキーメッセージを1セクション1〜3か所だけ強調
- 箇条書きで手順・要素を整理する
- 各セクションに逃げ道（「まずここだけでOK」「今日のゴール」）を置く
- 自己開示（「僕も最初は〜」）を要所に入れて、書き手の顔が見えるようにする
- 説教くさい締め・きれいにまとめすぎる締めはしない（言い切らずに終わってよい）

## AI感を消す（重要）

- 同じ主張を三段で言い換えない（「たとえば／言い換えると／つまり」の重ね打ちを避ける）
- 教科書的な書き出し（「近年〜」「〜について解説します」）を使わない。冒頭は読者の"あるある"か自分の実体験から入る
- クッション表現（「〜だったりします」等）の機械的な多用を避ける
- 設定ファイルに貼られたサンプル文があれば、そのリズムに寄せる

## 事実・正確性

- ツールの機能名・仕様、数値、制度、料金は、断定する前に **Web検索で裏を取る**
- 裏が取れないものは「〜の場合があります」等に弱めるか、書かない
- 変わりやすい情報には「◯年◯月時点」を添える

## 守ること（表現）

- 誇大な表現（絶対／必ず／誰でも／100％／日本一 等）を使わない
- 収入や成果は「目指す」等、断定を避ける

## 手順

1. 設定ファイルと承認済み構成を読み込む
2. リード（問題提示→解決イメージ→メリット→安心感）→ 各H2/H3 → まとめ＋CTA の順に書く
3. 事実は裏取りし、自分の言葉で書く（見本を写さない）
4. **採点＆修正ループを回す**（合格ライン＝総合95点以上）。詳細は下記
5. 合格したら、記事フォルダ `~/note-kit/note-draft/articles/<記事名>/article.md` に書き出す
6. 文字数と最終スコアを伝える

## 修正ループ（合格ライン：総合95点以上）

書き上げたら、仕上げる前に「採点→修正→再採点」を繰り返す。

- **採点する7項目**：文字数／テーマのキーワード／誇大表現の有無／トーン一致／独自性／事実の裏取り／検索されやすさ。各0〜100点で採点し、加重平均で総合点を出す（独自性・事実は各20%、他は各12%程度）
- **必ずWeb検索する**：独自性（特徴的な一文を3〜5本、1本ずつ検索）と事実確認は、毎回実際に検索して照合する。検索せずに合格にしない
- **回し方**：95点未満、または明らかな問題があれば、その指摘を反映して直し、再採点する。95点以上になるまで自動で繰り返す（1回ごとのユーザー確認は不要）
- **止まる条件**：何度直しても特定の項目が届かない、または事実の裏が取れない場合は、無理に数字を合わせず、どの項目がなぜ届かないかを報告して一度止まる

## Notionに保存する（設定がある場合だけ）

設定ファイルの「保存先のデータベースID」が空欄なら、**何もしない**。
書いてあるときは、保存前に一度だけ確認してから保存する。

## 注意

- 構成にない話を勝手に足して文字数を稼がない。必要なら構成の追記を提案する
- 迷ったら「これ、自分が書いた文章に読めるか？」を基準にする
