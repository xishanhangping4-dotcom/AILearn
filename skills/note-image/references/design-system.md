# 図解デザインの型

記事に差し込む図解を、全部同じ見た目に揃えるためのルール。
色は初期値です。`~/note-kit/profile.md` の「図解の色」に記入があれば、**そちらを優先**してください。

## カラー（初期値）

| 用途 | 色 |
|---|---|
| 背景 | クリーム／オフホワイト。上ほど淡いグラデ `linear-gradient(168deg,#fffdf9,#fdf4e7)` |
| アクセント（メインの色） | オレンジ `#F5822B`（淡い面 `#FDECDA`、細枠 `#f4b271`） |
| 濃色文字 | 濃紺 `#1B2A4A`（ほぼ黒） |
| 本文グレー | `#41495c` ／ 補足 `#6b7280` |
| 比較の「良くない側」 | グレー系。「良い側」はアクセント色 |
| チェックOK | グリーン `#3FA968` |

ステップごとに色を分けたいときは、アクセント色→緑→黄→紫→ピンクの順で。

## レイアウトの型（全画像で共通の3段）

1. **上段：見出し**
   - 極太ゴシック（`font-weight:900`）、`font-family:"Hiragino Sans","Noto Sans JP"`（Windowsでは自動的に游ゴシック/メイリオで描画される。ひな形に予備フォント設定済み）
   - キーワードを1つだけアクセント色に。さらに一語に**下線**（`::after` で太線を敷く）
2. **中段：図解の本体**
   - 2カラム比較 / 3ステップ / カード群 / チャット風 / フォルダツリー / 配線図
3. **下段：まとめ帯**
   - アクセント色の角丸帯に、白抜きの太字でまとめ一言。キーワードだけ濃紺に反転させると締まる
   - 先頭に濃紺丸のチェックアイコンを置く

## 部品

- **角丸カード**：白地 + アクセント色の細枠（`2.5px solid`）、`border-radius:22〜26px`、やわらかい影
- **番号バッジ**：丸いアクセント色に白抜き数字。カードの上辺に半分かぶせる（`top:-27px`）
- **チャット風**：濃紺のヘッダーバー + 吹き出し（AI＝グレー左寄せ / 自分＝淡いアクセント色で右寄せ）+ 入力欄
- **アイコン**：必ず**インラインSVG**（線画、`stroke-width:3`前後）。**絵文字は使わない**

## 文字まわりの注意

- `word-break:keep-all; line-break:strict` を body に入れる（日本語が単語の途中で折れるのを防ぐ）
- 長い行は読点や文節の位置で `<br>` を手動で入れると自然
- カード幅が狭くて1行に入らないときは、フォントを1px下げるかカード幅を広げる
- **下帯の文字が不自然に空くとき**：帯の中のテキスト全体を1つの `<span>` で囲む。横並びの設定（flexのgap）が語と語の間にも効いてしまうため

## 出力サイズの目安

- 横長の図解：`1600 x 750`（シンプル）〜 `1600 x 1130`（要素が多いもの）
- 中身に対して縦が長すぎると、下に間延びした余白ができる。カードの下端と帯の間が空きすぎたら、高さを50〜150px縮める
- 人物イラスト単体：`1024 x 1024`
- 変換スクリプトは2倍の解像度で書き出すので、実ファイルは指定の2倍になる（note掲載には十分）

## 作り方の考え方

日本語のレイアウトは繊細なので、**枠・文字・アイコン・カードはコード（HTML/CSS）で作る**のが確実です。
人物やロボットのイラストだけ画像生成AIで作って配置する、という組み合わせが崩れにくい作り方になります。
