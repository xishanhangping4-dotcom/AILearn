# note-image — note用の図解を作る

記事に差し込む画像を、記事全体で統一された見た目で作るためのスキル。

## 参照

- あなたの設定：`~/note-kit/profile.md`（色の設定があればそれを優先する）
- デザインの型：`references/design-system.md` — **作り始める前に読む**
- 図解のひな形：`assets/figure-template.html` — コピーして使う

## 前提（実行環境）

画像を作るスクリプトは **`~/note-kit/note-draft`** で動かす。

- 図解 … 追加の料金はかからない（`playwright` を使う。導入手順でセットアップ済み）
- 人物イラスト … OpenAIのAPIキーが必要（1枚あたり約3〜15円）。`.env` に設定がなければ**作らず、図解だけで進める**

## 手順

### 1. 記事を読んで画像を設計する

記事本文を読み、**どの見出しの後に・どんな画像を置くか**を決める。各画像について：

- 種類：ステップ図 / 2カラムの比較 / カード3枚 / チャット風の図
- 上段の見出し（キーワードを1つだけ色付きにする）
- 中身（カードの数・文言）
- 下段のまとめ一言

### 2. 図解を作る（HTML/CSS → PNG）

1. `assets/figure-template.html` をコピーして中身を差し替える（共通の見た目は入っている）
2. PNGに変換する：

```bash
cd ~/note-kit/note-draft
node scripts/render-figure.mjs <作ったhtml> articles/<記事名>/images/<名前>.png <幅> <高さ>
```

> **幅と高さは、HTMLの `html,body{width:...;height:...}` と必ず同じ値にする。**
> ひな形の初期値は 1600×900。ここがずれると、下帯が切れたり余白が出たりする。
> 高さを変えるときは、HTML側と引数の両方を直す。

3. できたPNGを**必ず開いて目で確かめる**。毎回この4点をチェック：
   - 文字が枠や下帯に**重なっていない**か（収まらなければ高さを増やす）
   - 改行が**単語の途中で割れていない**か（長い行は読点で `<br>` を入れる）
   - **絵文字を使っていない**か（安っぽく見える。必ずSVGアイコンにする）
   - 装飾を**盛りすぎていない**か（控えめが読みやすい）

> 下帯の文字が不自然に空くときは、帯の中のテキスト全体を1つの `<span>` で囲む（横並びの設定で語と語の間に隙間が入るため）。

### 3. 人物イラストを作る（APIキーがある場合のみ）

```bash
cd ~/note-kit/note-draft
node scripts/gen-illust.mjs "<英語のプロンプト>" articles/<記事名>/images/<名前>.png 1024x1024 transparent high
```

- 第4引数 `transparent` で背景透過、`opaque` で背景あり
- 背景を確実に消すコツ：プロンプトに `die-cut sticker style, isolated subject on a fully transparent background, no background, no gradient, no halo, no shadow, no text` を入れる
- 生成後は必ず目で確認する。イメージと違えばプロンプトを直して**1回だけ**作り直す（毎回課金される。何度も試さない）

### 4. 記事に挿入する

各画像を、該当する見出しの後ろに `![説明](./images/xxx.png)` の形で入れる。
